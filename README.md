# Ускорение Android-телевизора

Многие Smart TV работают на **Яндекс ТВ** или **Android TV**. Обе системы построены на Android,
поэтому их можно настроить с компьютера через ADB **без прошивки, без root и без риска «окирпичить» ТВ**.
Рассчитано на Яндекс ТВ (Android 9 и новее), подходит и для других Android-телевизоров.

`tvtool.py` умеет:

- **диагностика**: сколько памяти и места, какие приложения больше всего занимают ОЗУ, советы (`info`);
- **чистка**: отключить лишние приложения или запретить им работать в фоне (`scan` → `apply`);
- **ускорение**: анимации, очистка кэша, полная компиляция основных приложений (`speedup --max`);
- **освобождение памяти** перед просмотром (`boost`);
- **понижение разрешения интерфейса** для слабого видеочипа (`resolution 720`, эксперимент);
- **установка APK** и автозапуск обхода блокировок YouTube (`install`, `vpn`);
- **откат всего** одной командой (`restore`).

Ничего не удаляется. Скрипт не даст тронуть то, без чего ТВ сломается: систему, картинку, звук, пульт, HDMI,
текущий главный экран, клавиатуру, обход блокировок, Кинопоиск и службу Projectivy.

## Самый простой способ: приложение «ТВ Тюнер» с флешки (без компьютера)

`dist/TVTuner.apk` — приложение для телевизора, которое делает всё то же самое прямо на ТВ, с пульта.
Оно подключается к отладке самого телевизора (так же, как компьютер с adb), поэтому root не нужен.

**Что нужно один раз сделать руками** (без этого ни одна программа не получит доступ):

1. **Настройки → Об устройстве** → 7 раз нажмите **«Сборка»** (если её нет — **«Версия ПО»**).
2. **Настройки → Для разработчиков** → включите **«Отладка по USB»** и **«Отладка по сети»** (если есть).

**Флешка:**

```
ФЛЕШКА
├── TVTuner.apk          ← из папки dist этого репозитория
└── apk                  ← папка с приложениями, которые поставятся сами
    ├── ByeByeDPI.apk
    ├── SmartTube.apk
    └── Projectivy.apkm
```

Подходят обычные `.apk` и архивы из нескольких APK: `.apkm` (APKMirror), `.apks`, `.xapk`.
Для Projectivy на APKMirror выбирайте вариант с **Minimum Version не выше Android 9**
(обычно это «arm64-v8a + armeabi-v7a, Android 6.0+», он помечен как BUNDLE — это нормально).

**На телевизоре:**

1. Вставьте флешку, откройте её в файловом менеджере ТВ и запустите `TVTuner.apk`.
   Если ТВ спросит про установку из неизвестных источников — разрешите.
   Если ТВ не умеет открывать APK с флешки, установите его один раз с компьютера (`tvtool.py`, пункт 8).
2. Откройте **«ТВ Тюнер»**. Появится запрос **«Разрешить отладку?»** — отметьте **«Всегда разрешать»** и нажмите **ОК**.
3. Нажмите **«Сделать всё автоматически»**: приложения с флешки установятся, ТВ ускорится,
   обход блокировок YouTube включится и будет запускаться сам. Откроется ByeByeDPI — нажмите
   в нём «Подключить» и вернитесь в «ТВ Тюнер».
4. **«Чистка приложений»**: нажимайте на приложения, чтобы выбрать «запретить фон» или «отключить»,
   затем **«Применить»**. Самые тяжёлые — сверху, защищённые изменить нельзя.
5. **«Перезагрузить ТВ»**.

Всё отменяется кнопкой **«Вернуть всё как было»**. Остальные кнопки повторяют команды `tvtool.py`:
диагностика, ускорение, освобождение памяти, интерфейс 720p и **игровой режим** (см. ниже).

## 1. Подготовка телевизора

1. **Настройки → Об устройстве** → прокрутите вниз до **«Сборка»** и нажмите на этот пункт 7 раз подряд,
   пока не появится «Вы стали разработчиком». Если пункта «Сборка» нет, нажмите 7 раз на «Версия ПО».
2. **Настройки → Для разработчиков**: включите **«Отладка по USB»** и **«Отладка по сети»**
   (если такой пункт есть).
3. IP-адрес телевизора: **Настройки → Об устройстве → Статус**, например `192.168.1.57`.
4. Заодно проверьте **Настройки → Об устройстве → Обновление системы**: новые прошивки Яндекс ТВ
   сами по себе часто работают быстрее.

## 2. Подготовка компьютера (Windows)

1. Установите Python 3 с сайта python.org (при установке поставьте галочку **«Add Python to PATH»**).
2. Скачайте **SDK Platform-Tools** с developer.android.com/tools/releases/platform-tools
   и распакуйте, например, в `C:\platform-tools`.
3. Положите `tvtool.py` в ту же папку `C:\platform-tools` и **запустите его двойным щелчком**: откроется меню.
   Если окно сразу закрывается, откройте эту папку, наберите в адресной строке проводника `cmd`,
   нажмите Enter и выполните `python tvtool.py`.

На Linux/macOS: `sudo apt install adb` или `brew install android-platform-tools`.
Компьютер и телевизор должны быть в одной сети.

## 3. Меню

```
=== Ускорение телевизора ===
   1. Подключиться к телевизору
   2. Диагностика: память, диск, что тормозит
   3. Быстрое ускорение (безопасно)
   4. Максимальное ускорение
   5. Создать список приложений (my_packages.txt)
   6. Применить my_packages.txt
   7. Освободить память перед просмотром
   8. Установить все APK из папки apk
   9. Перезагрузить телевизор
  10. Вернуть всё как было
  11. Игровой режим (Moonlight)
  12. Выйти из игрового режима
  13. Защищённый DNS (если YouTube не грузится)
  14. Обычный DNS
   0. Выход
```

IP запоминается: в следующий раз скрипт подключится к телевизору сам.

## 4. Максимальная скорость: по шагам

1. **Подключение и диагностика**: пункты 1 и 2. Посмотрите, что занимает память, и прочитайте советы.
2. **Чистка**: пункт 5 создаст `my_packages.txt`. Откройте его в Блокноте. Приложения отсортированы
   по занимаемой памяти, самые тяжёлые сверху. Для каждой строки:
   - **уберите `#`** в начале, и приложение будет **отключено** (не запускается, памяти не занимает);
   - **замените `#` на `bg`**, и приложение останется, но **не будет работать в фоне**. Подходит для
     онлайн-кинотеатров и прочего, что открываете изредка;
   - строку без изменений скрипт не трогает.

   Сохраните файл и выберите пункт 6.
3. **Ускорение**: пункт 4. Выключит анимации, очистит кэш, скомпилирует ваши основные приложения
   (главный экран, Кинопоиск, установленные вами), чтобы они быстрее запускались и меньше подтормаживали.
   Компиляция занимает несколько минут, и ей нужно хотя бы 500 МБ свободного места.
4. **Перезагрузка**: пункт 9.
5. **Приложения**: положите APK в папку `apk` рядом со скриптом (ByeByeDPI, SmartTube, Projectivy и т. д.)
   и выберите пункт 8. Затем настройте обход блокировок (см. ниже).
6. **По желанию, эксперимент**: `python tvtool.py resolution 720`. Интерфейс будет отрисовываться в 720p
   вместо 1080p. Слабому видеочипу это сильно облегчает работу, а видео всё равно показывается
   в полном разрешении. Проверьте меню, приложения, HDMI и антенну. Если что-то выглядит не так:
   `python tvtool.py resolution reset`.

Перед просмотром тяжёлого контента можно освобождать память пунктом 7, но обычно это не нужно.

### Что обычно можно отключать

Отключайте понемногу и проверяйте, всё ли работает:

- предустановленные приложения, которыми вы не пользуетесь (онлайн-кинотеатры, игры, магазины);
- рекламные и рекомендательные сервисы (в названии `ads`, `promo`, `recommend`, `feedback`);
- сервисы отчётов и аналитики (`analytics`, `report`, `log`, `crash`).

**Не трогайте** строки с пометкой `[ЗАЩИЩЁН]`, а также пакеты с `tv`, `hdmi`, `input`, `remote`,
`bluetooth`, `ota`/`update`, если не уверены, что это такое. Если сомневаетесь, лучше поставить `bg`
вместо полного отключения.

## Все команды

| Команда | Что делает |
|---|---|
| `connect 192.168.1.57` | подключиться к ТВ |
| `info` | диагностика и советы |
| `scan` | создать `my_packages.txt` |
| `apply` | применить разметку из `my_packages.txt` |
| `disable` / `enable <пакет>` | отключить или включить приложение |
| `restrict` / `allow <пакет>` | запретить или разрешить работу в фоне |
| `speedup` | анимации ×0,5, очистка кэша, оптимизация |
| `speedup --max` | без анимаций + полная компиляция + очистка ОЗУ |
| `compile [пакеты]` | только полная компиляция |
| `boost` | освободить ОЗУ |
| `resolution 720` / `reset` | понизить интерфейс до 720p или вернуть |
| `install [файлы или папка]` | установить APK и архивы `.apkm`/`.apks`/`.xapk` (по умолчанию из папки `apk`) |
| `vpn` / `vpn --off` | автозапуск ByeDPI при включении ТВ |
| `restore` | вернуть всё: приложения, фон, анимации, разрешение |
| `speedup --undo` | вернуть только анимации |
| `dns` / `dns --off` | защищённый DNS (DNS-over-TLS), если YouTube «не находится» / вернуть обычный |
| `game` / `game --off` | игровой режим: подготовить ТВ и запустить Moonlight / выйти из него |
| `reboot` | перезагрузить ТВ |

Все команды запускаются как `python tvtool.py <команда>`.

## YouTube без замедления (аналог zapret)

Сам `zapret` требует root, поэтому на телевизоре его не запустить. На Android без root то же самое делает
**ByeByeDPI** (github.com/romanvht/ByeByeDPI): это локальный «VPN», который не гонит трафик
через чужой сервер, а только меняет пакеты так, чтобы их не распознавала система блокировок.

```
python tvtool.py install ByeByeDPI.apk SmartTube.apk
python tvtool.py vpn                    # запускать ByeDPI вместе с телевизором
```

Один раз откройте ByeByeDPI на ТВ, нажмите «Подключить» и разрешите запрос. Если YouTube всё ещё
тормозит, в настройках ByeByeDPI попробуйте другие стратегии (в приложении есть подбор).
Убрать автозапуск: `python tvtool.py vpn --off`.

**Если SmartTube пишет «Unable to resolve host www.youtube.com»**, провайдер подменяет DNS-ответы
для YouTube, и смена DNS в ByeByeDPI не помогает. Нажмите в «ТВ Тюнере» **«Защищённый DNS»**
(или `python tvtool.py dns`): он включит встроенный в Android 9 DNS-over-TLS, по очереди попробует
Google, Cloudflare, Quad9 и AdGuard, проверит, что YouTube находится, и оставит первый рабочий.
Если не сработает ни один — сам вернёт обычную настройку. Откат вручную: «Обычный DNS» (`dns --off`).

Для скорости:

- **Пропускайте через обход только YouTube.** Если в ByeByeDPI есть выбор приложений, оставьте в нём
  SmartTube. Кинопоиску и остальному обход не нужен, а лишний трафик через VPN нагружает слабый процессор.
- **В SmartTube не выбирайте качество выше 1080p**: у телевизора Full HD-экран, 4K только зря нагружает
  процессор и сеть. Если видео дёргается, в меню качества выберите вариант с кодеком **AVC (H.264)**.
- Если у вас роутер Keenetic или роутер с OpenWrt, `zapret` лучше поставить прямо на роутер:
  тогда обход работает сразу для всех устройств дома, и телевизор не тратит на это ресурсы.

## Кинопоиск

Пакеты, в названии которых есть `kinopoisk`, программа защищает: их нельзя отключить или ограничить.
Главный экран Яндекса тоже защищён, а Кинопоиск встроен в него, поэтому он продолжит работать.

## Свой внешний вид

Установите **Projectivy Launcher** и включите в его настройках **«Переопределение лаунчера»**
(Launcher override). Кнопка «Домой» тогда будет открывать Projectivy вместо экрана Яндекса,
а сам Яндекс ТВ с Кинопоиском останется на месте и запускается как приложение.
Служба Projectivy автоматически защищена от отключения скриптом.

## Игры с компьютера на телевизоре (Moonlight)

**Moonlight** показывает на телевизоре игры, которые работают на вашем компьютере: ПК считает графику,
а ТВ получает видео по домашней сети. Всё бесплатно, покупать нужно только геймпад.

**Что нужно:**

- компьютер с Windows 10/11 и видеокартой NVIDIA (GTX 900 и новее), AMD (RX 400 и новее) или свежей Intel;
- сеть: компьютер — кабелем к роутеру, телевизор — кабелем или по Wi-Fi 5 ГГц;
- геймпад: надёжнее всего **DualShock 4** или **Xbox One S** по Bluetooth, либо любой проводной USB-геймпад.

**Установка:**

1. На компьютер поставьте **Sunshine** (GitHub → `LizardByte/Sunshine` → Releases). Откройте
   `https://localhost:47990` (предупреждение о сертификате — нормально) и задайте логин и пароль.
2. APK **Moonlight** (GitHub → `moonlight-stream/moonlight-android` → Releases) положите на флешку в папку `apk`
   и нажмите в «ТВ Тюнере» «Установить APK с флешки».
3. Геймпад подключите: **Настройки ТВ → Пульты и аксессуары → Добавить устройство**
   (на DualShock 4 зажмите Share + PS до мигания).
4. В «ТВ Тюнере» нажмите **«Игровой режим (Moonlight)»**. Он:
   - проверит, виден ли геймпад и подходит ли сеть (кабель, Wi-Fi 5 ГГц или 2,4 ГГц и уровень сигнала);
   - **приостановит обход блокировок** — VPN заворачивает в себя и домашнюю сеть, из-за этого стрим тормозит
     или не запускается;
   - закроет фоновые приложения и освободит память;
   - через 6 секунд откроет Moonlight.
5. При первом запуске Moonlight найдёт компьютер и покажет PIN — введите его в Sunshine на вкладке **PIN**.
   В настройках Moonlight: **1080p, 60 FPS, битрейт 15–20 Мбит/с, кодек H.264** (если всё плавно — можно HEVC).
6. В настройках изображения телевизора включите режим **«Игра»** — он заметно уменьшает задержку.
7. После игры нажмите **«Выйти из игрового режима»**: откроется ByeByeDPI, нажмите «Подключить».
   Или просто перезагрузите ТВ — обход включится сам.

## Полезные привычки

- **Раз в несколько дней перезагружайте ТВ полностью** (пункт 9 или «Перезагрузить» в настройках).
  Выключение с пульта на таких моделях обычно лишь переводит их в сон, и память не очищается.
- **Держите свободным хотя бы 1–1,5 ГБ на диске.** Почти заполненная память сильно тормозит.
- **Не ставьте «ускорители», «очистители» и антивирусы.** Они сами постоянно работают в фоне
  и занимают ту память, которую должны освобождать.

## Как вернуть всё

- `python tvtool.py restore` (пункт 10) включает отключённые приложения, разрешает фон,
  возвращает заводские анимации и разрешение. Обход блокировок при этом остаётся.
- Если ТВ совсем не загружается: **сброс к заводским настройкам** тоже возвращает всё назад.

## Почему не своя прошивка

Своя прошивка для телевизора, к сожалению, не вариант. Драйверы матрицы, видеодекодера и тюнера закрыты,
а загрузчик проверяет подпись. Ошибка почти наверняка превратит телевизор в «кирпич» и лишит гарантии.
Отключение лишнего плюс лёгкий лаунчер дают большую часть возможного прироста скорости без этого риска.

Если ТВ на слабом железе (по `info` около 1 ГБ ОЗУ и меньше), то самое заметное улучшение даст
внешняя приставка (Android TV-бокс, Google TV Streamer и т. п.).
Телевизор тогда работает просто как экран.

## Для разработчика: сборка «ТВ Тюнера»

Исходники в `android/`. Android SDK не нужен, только JDK 17+ и Python 3:

```
python android/build.py          # собирает dist/TVTuner.apk
python android/test/run_tests.py # проверка ADB-клиента и всех действий на имитации ТВ
```

`build.py` скачивает из Maven Central API Android 9 (для компиляции) и `dx`, сверяет их контрольные суммы,
сам собирает двоичные `AndroidManifest.xml` и `resources.arsc` и подписывает APK ключом
`android/keystore/tvtuner.p12`. Ключ хранится в репозитории, чтобы новые версии ставились поверх старых.
Иконку и баннер рисует `android/tools/make_icons.py` (нужен Pillow).
