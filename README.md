# ForeverCoach

Бесплатный аддон-помощник ротации для **WoW Forever**. Подсказывает следующую способность под твой класс, билд, уровень и ситуацию. Нажимаешь ты сам: аддон только подсказывает, на экране минимум.

> Статус: **этап 0 (разведка) и начало этапа 1 (ядро и чернокнижник)**. Аддон уже собирает подсказки для чернокнижника на прокачке, но проверка в игре ещё впереди. По плану этапы идут по порядку: следующий начинается только после проверки предыдущего в игре.

## Что уже есть

| Часть | Готово | Где |
|---|---|---|
| Разведка (этап 0) | Отдельный аддон записывает, какие данные видны в бою и вне боя, и выгружает книгу заклинаний, таланты, способности демона, цены учителя и сданные квесты | `ForeverCoach_Probe/` |
| Состояние игры | Уровень, выученные ранги, таланты, здоровье, мана, цель, демон, враги рядом, режим | `Core/State.lua` |
| Скрытые в бою значения | Каждое значение может прийти «секретным». Тогда аддон берёт безопасное допущение (полное здоровье, долгоживущая цель) или свои таймеры от кастов | `Core/API.lua`, `Core/Timers.lua` |
| Язык условий | `debuff.corruption.down & target.ttd > 8` и т. п. Строки компилируются в функции один раз | `Core/Conditions.lua`, [docs/PROFILES.md](docs/PROFILES.md) |
| Движок | Профиль идёт сверху вниз. Есть прогноз на 1–2 шага с учётом ГКД, каста, дебаффов, откатов и проков, а также ряды «основной / защита / кулдаун» | `Core/Engine.lua` |
| Время до смерти цели | По скорости падения здоровья | `Core/TTD.lua` |
| Режимы | Прокачка, подземелья и рейды, PvP. Определяются сами, можно закрепить вручную | `Core/Modes.lua` |
| Распознавание билда | Ветка с наибольшим числом очков плюс ключевые таланты. Если профиль не найден, берётся общий с пометкой «приблизительный» | `Core/BuildMatcher.lua` |
| Чернокнижник | Заклинания и ранги 1–60, профили прокачки: общий и «Колдовство» | `Data/Spells/Warlock.lua`, `Data/Profiles/` |
| Экран | Главная иконка с клавишей, откатом и свечением на прок. Следующие иконки (0–2), слот защиты слева, слот кулдауна справа, метка AoE, строка подготовки вне боя. При наведении видно, почему предложено именно это | `UI/HUD.lua` |
| Настройки | Вид, пороги, режим, звук на прок, кнопка у мини-карты | `UI/Settings.lua`, `UI/Minimap.lua` |
| Автотесты | 56 тестов: язык условий, сценарии движка, скрытые значения, данные, разведка, интерфейс | `tests/` |

Дальше по плану: билды из Talents Forever и планировщик (этап 2), разбор боя (этап 3), подземелья и рейды (этап 4), PvP (этап 5), остальные классы (этап 6), лекари (этап 7).

## Установка

1. Скопируй папки `ForeverCoach` и `ForeverCoach_Probe` в `_forever_\Interface\AddOns`.
2. Запусти игру, в списке аддонов должны быть включены оба.
3. Пройди разведку: [docs/STAGE0.md](docs/STAGE0.md). После неё `ForeverCoach_Probe` можно удалить.

## Команды

| Команда | Что делает |
|---|---|
| `/fc` | Настройки (закрываются по Esc) |
| `/fc toggle` | Показать или скрыть подсказки |
| `/fc lock`, `/fc unlock` | Закрепить блок или двигать его мышью |
| `/fc mode auto \| leveling \| group \| pvp` | Закрепить режим |
| `/fc debug` | Писать в чат причину каждой подсказки. `*` у значения: игра его скрыла, взято допущение |
| `/fc state` | Снимок игры глазами аддона, включая то, что скрыто |
| `/fc perf` | Сколько миллисекунд занимает обновление |
| `/fc reset` | Сбросить положение и настройки |
| `/fc builds`, `/fc plan`, `/fc recap` | Окна следующих этапов |

Клавиши по умолчанию не назначены: «Назначение клавиш» → «Модификации» → ForeverCoach.

## Как устроено

```
ForeverCoach/
  ForeverCoach.toc       ## Interface: 16001
  Bindings.xml           клавиши окон и показа подсказок
  Locales/               ruRU, enUS (названия заклинаний берутся из клиента по ID)
  Core/                  Init, Events (шина), API (совместимость и секреты), Data,
                         Timers (свои таймеры), TTD, Modes, State, BuildMatcher,
                         Conditions, Engine, Loop (цикл обновления и команды)
  UI/                    ActionBars (клавиши), HUD, Settings, Minimap
  Data/                  Spells/<Класс>.lua, Profiles/<Класс>_<Билд>_<Режим>.lua,
                         Builds.lua, Quests.lua
ForeverCoach_Probe/      аддон разведки этапа 0
tests/                   busted + заглушки API игры (вне игры, в аддон не входит)
tools/validate_profiles.lua   проверка профилей и данных
docs/                    формат профилей, план этапа 0
```

Модули общаются через шину событий (`Core/Events.lua`) и не лезут во внутренности друг друга. Данные отделены от кода: после патча правятся таблицы в `Data/`, код не трогается. Загружаются данные только твоего класса.

### Скрытые значения (ограничения Midnight в Forever)

В бою часть значений приходит «секретной»: их можно показать на экране, но в Lua нельзя сравнить или посчитать. Аддон к этому готов:

- каждый вызов API идёт через `Core/API.lua`: секрет превращается в «неизвестно»;
- неизвестное здоровье считается полным: защита не всплывёт по ложной тревоге. Неизвестное время жизни цели считается долгим: дебаффы вешаются;
- свои дебаффы, откаты, ГКД и текущий каст отслеживаются собственными таймерами по событиям `UNIT_SPELLCAST_*`. Если игра показывает ауры, верим игре;
- прок «Теневой транс» распознаётся ещё и по подсветке заклинания самим клиентом.

Что именно скрыто в Forever, покажет разведка. По её итогам допущения уточняются.

## Разработка

Нужны Lua 5.1, busted и luacheck (Ubuntu: `apt-get install lua5.1 lua-busted lua-check`).

```sh
busted                                  # автотесты
lua5.1 tools/validate_profiles.lua      # проверка профилей и данных
luacheck ForeverCoach ForeverCoach_Probe tools tests
```

Тот же набор запускается в GitHub Actions на каждый push.

Сценарий из ТЗ «уровень 12, Демон Бездны, у цели 20% здоровья → Похищение души» лежит в `tests/engine_spec.lua`, рядом остальные сценарии.
