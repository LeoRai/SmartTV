# Ускорение телевизора Novex

Большинство Smart TV Novex работают на **Яндекс ТВ** или **Android TV**. Обе системы построены на Android,
поэтому их можно настроить с компьютера через ADB **без прошивки, без root и без риска «окирпичить» ТВ**.

`tvtool.py` умеет:

- показывать модель, версию Android, свободную память и место на диске (`info`);
- сохранять список всех приложений в файл, где вы отмечаете ненужные (`scan`);
- **отключать** лишние приложения: они перестают запускаться и съедать память (`disable`);
- возвращать всё как было одной командой (`restore`);
- ускорять анимации, чистить кэш и оптимизировать приложения (`speedup`);
- ставить любые APK-файлы с компьютера (`install`).

Приложения **не удаляются**, а только отключаются. Пакеты, отвечающие за картинку, звук, пульт и HDMI,
защищены: скрипт откажется их трогать.

---

## 1. Подготовка телевизора

1. **Настройки → Устройство (или «О телевизоре») → Сборка (Номер сборки)**: нажмите на этот пункт
   7 раз подряд, пока не появится «Вы стали разработчиком».
2. **Настройки → Для разработчиков**: включите **«Отладка по USB»** и **«Отладка по сети»**
   (если такой пункт есть).
3. Узнайте IP-адрес телевизора: **Настройки → Сеть → (ваша сеть)**, например `192.168.1.57`.

Названия пунктов зависят от версии прошивки. Если «Для разработчиков» не появляется, напишите точную модель ТВ.

## 2. Подготовка компьютера (Windows)

1. Установите Python 3 с сайта python.org (при установке поставьте галочку **«Add Python to PATH»**).
2. Скачайте **SDK Platform-Tools** с developer.android.com/tools/releases/platform-tools
   и распакуйте, например, в `C:\platform-tools`.
3. Положите `tvtool.py` в ту же папку `C:\platform-tools`, откройте её, в адресной строке проводника
   наберите `cmd` и нажмите Enter.

На Linux/macOS: `sudo apt install adb` или `brew install android-platform-tools`.

Компьютер и телевизор должны быть в одной сети.

## 3. Использование

```
python tvtool.py connect 192.168.1.57   # подключиться (на ТВ нажмите «Разрешить»)
python tvtool.py info                   # что за система и сколько памяти
python tvtool.py speedup                # ускорить анимации, очистить кэш
python tvtool.py scan                   # создать my_packages.txt со списком приложений
```

Откройте `my_packages.txt` в Блокноте. Каждая строка — приложение, по умолчанию закомментированное (`#`).
**Уберите `#`** перед теми, что хотите отключить, и сохраните файл. Затем:

```
python tvtool.py disable -f my_packages.txt
python tvtool.py reboot
```

Если что-то перестало работать:

```
python tvtool.py restore                # включить обратно всё отключённое
python tvtool.py speedup --undo         # вернуть стандартные анимации
```

Самый надёжный вариант отката, если ТВ совсем не загружается: **сброс к заводским настройкам**.
Он включает все отключённые приложения обратно.

### Что обычно безопасно отключать

Отключайте по одному-два приложения и проверяйте, всё ли работает:

- предустановленные приложения, которыми вы не пользуетесь (онлайн-кинотеатры, игры, магазины);
- рекламные и рекомендательные сервисы (в названии `ads`, `promo`, `recommend`, `feedback`);
- сервисы отчётов и аналитики (`analytics`, `report`, `log`, `crash`).

**Не трогайте**: всё с пометкой `[ЗАЩИЩЁН]` и `[ТЕКУЩИЙ ЛАУНЧЕР]`, а также пакеты с названиями
`tv`, `hdmi`, `input`, `remote`, `bluetooth`, `ota`/`update`, `keyboard`, если не уверены, что это такое.

### Больше свободы в приложениях

```
python tvtool.py install SmartTube.apk Projectivy.apk
```

Популярные варианты для Android-ТВ:

- **SmartTube**: YouTube без рекламы;
- **Projectivy Launcher** или **FLauncher**: лёгкий и быстрый главный экран вместо стандартного;
- **Send Files to TV**: передача файлов с телефона;
- **VLC** или **Kodi**: проигрывание любых видео с флешки или из домашней сети.

Скачивайте APK только с официальных сайтов или GitHub-страниц проектов.
Сторонний лаунчер на Яндекс ТВ иногда не назначается главным экраном. В этом случае его можно
запускать как обычное приложение.

## Почему не своя прошивка

Своя прошивка для Novex, к сожалению, не вариант. Драйверы матрицы, видеодекодера и тюнера закрыты,
а загрузчик проверяет подпись. Ошибка почти наверняка превратит телевизор в «кирпич» и лишит гарантии.
Отключение лишнего плюс лёгкий лаунчер дают большую часть возможного прироста скорости без этого риска.

Если ТВ на слабом железе (1 ГБ RAM и меньше по `info`), то самое заметное улучшение даст
внешняя приставка (Android TV-бокс, Google TV Streamer и т. п.) за 3–6 тыс. руб.
Телевизор тогда работает просто как экран.
