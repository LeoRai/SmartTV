# Этап 1: ядро и чернокнижник — проверка в игре

Этап закрыт, когда (по ТЗ):

- [x] все автотесты сценариев проходят — `busted`, в CI на каждый push;
- [ ] в игре на уровнях 1–30 нет ошибок Lua — на 12 уровне ошибок нет (несколько часов игры), проверка идёт дальше по мере прокачки;
- [ ] подсказка меняется сразу после покупки нового ранга.

Требования к качеству:

- [x] **обновление в среднем меньше 1 мс** — в игре (Forever 1.60.1, чернокнижник 12 уровня): 2589 обновлений, в среднем 0,359 мс, максимум 1,946 мс (`/fc perf`). Редкие пики — пересчёт выученных заклинаний и талантов после событий игры, не каждый кадр;
- [x] частота — не чаще 10 раз в секунду (цикл в `Core/Loop.lua`).

Ещё посмотреть в игре:

- [x] блок в бою выглядит и работает нормально (проверено игроком);
- [ ] Камень здоровья появляется на слоте защиты при здоровье ниже 35% (ворота по здоровью);
- [ ] Похищение души появляется поверх главной иконки, когда у цели около 20% и осколков меньше трёх;
- [x] подсветка кнопки на панели, клавиши на иконках, окно настроек.
